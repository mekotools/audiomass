# mekotools/audiomass

**Öffentliches Spiegel-Repo des MekoTools-Katalogs.** Enthält keine eigene
Software: Der Inhalt ist das fertige Container-Abbild, das hier veröffentlicht
wird, damit es **ohne Anmeldung** gezogen werden kann.

- Werkzeug: AudioMass (Audio- und Wellenform-Editor im Browser, pkalogiros/AudioMass)
- Bezug: `docker pull ghcr.io/mekotools/audiomass:latest`
- Zweck: Medienkompetenz und Medienbildung für Lehrkräfte (Projekt MekoTools)
- Bauvorschrift: `tilllt/mekotools/mekotools-audiomass-21f5ee13` (interne GitLab-Instanz),
  Quelltext-Stand `pkalogiros/AudioMass` @ `21f5ee13` — Lizenz: Lizenzdatei nicht standardisiert — vor der Katalogaufnahme zu klaeren

Die Quelldaten des Abbilds liegen im internen Bau-Repo; hier steht nur das
veröffentlichte Ergebnis samt Zuliefer-Workflow.
